# Grower search

## Steps

1. Restate the decision the grower is trying to make.
2. Classify intent: environment, root zone, grow memory, sensor truth, or cautious AI.
3. Gather primary sources. Cite them.
4. Record every metric as measured, `UNKNOWN`, or `BLOCKED`. Do not invent volume, difficulty, CPC, or traffic.
5. Note One-Tent Loop fit and what Verdant should not publish.
