# Inter font assets

These static TTF files come from the official Inter 4.1 release:

- Source: `https://github.com/rsms/inter/releases/tag/v4.1`
- Archive: `Inter-4.1.zip`
- Files: `extras/ttf/Inter-Regular.ttf`, `Inter-SemiBold.ttf`, `Inter-Bold.ttf`
- License: SIL Open Font License 1.1; preserved verbatim in `LICENSE.txt`

Verdant uses these files only while rasterizing deterministic Open Graph cards.
Do not replace them without intentionally regenerating and reviewing the stored
OG-card baselines.
