# Verdant SEO 30/60/90-day roadmap

## Days 0–30 — foundation

- Complete route/indexation inventory and safe P1 technical fixes.
- Establish an authenticated GSC/GA4 baseline or retain explicit **NO_BASELINE** status.
- Resolve shared-registry PR overlap and publish the two reviewed lighting pages.
- Implement the 20 contextual links in the lighting map.
- Start the weekly scorecard using redacted aggregate data only.

**Exit evidence:** route-policy tests pass; production deployment is confirmed; GSC workflow has a real tracked finding or an explicit owner decision; two pages have visible schema parity and review provenance.

## Days 31–60 — validate and deepen one cluster

- Review lighting impressions, clicks, queries, and landing-page behavior from an authenticated source.
- Improve only pages with an evidence-backed opportunity: title/snippet, opening answer, missing internal path, or cited clarification.
- Publish one or two of the remaining lighting support pages only if the first pages show demand or product relevance.
- Decide whether fixture previews are acquisition assets or noindex-only demos.
- Add truthful per-page editorial review/publication provenance before Article date fields are used.

**Exit evidence:** one comparable weekly baseline, a documented query-to-page decision, no new duplicate pages, and every deployed content page has an update trigger.

## Days 61–90 — choose the second cluster with evidence

- Compare lighting results against GSC/GA4 and product conversion signals.
- Validate or reject the nutrient/Cronk hypothesis with authenticated data; do not infer it from anecdote.
- If nutrients win, first resolve duplicated brand-page content, disclosure, manufacturer versioning, and a neutral pH/EC evidence pillar.
- If another cluster wins, create one pillar/supporting map and five briefs before publishing.
- Review sitemap growth, static-head coverage, monitoring cap/rotation, and Lighthouse results.

**Exit evidence:** one proven operating loop: high-intent question → useful visible answer → relevant Verdant workflow → measurable, privacy-safe next action → weekly review.
